# ♿ Guia de Segurança Digital | Web Inclusiva e Acessibilidade

Aplicação web interativa e acessível desenvolvida como projeto prático do curso de Programação Web (Alura / Start). O projeto une conscientização sobre **Direitos Digitais e Segurança na Internet** com recursos reais de **Acessibilidade Web** para pessoas com deficiência visual ou baixa visão.

---

## 🚀 Funcionalidades Implementadas

* **Nuvem de Dados Dinâmica (JavaScript):** Renderização dinâmica dos cartões informativos a partir de uma estrutura de objetos (`script.js`) com filtragem por categorias (*Privacidade & LGPD*, *Prevenção de Golpes* e *Senhas & Contas*).
* **Controle de Tamanho de Fonte (`A+` / `A-` / `A`):** Ajuste dinâmico da escala tipográfica da página por meio de variáveis CSS (`--tamanho-base`).
* **Modo Alto Contraste:** Alternância instantânea para paleta de cores de alto contraste (fundo preto com texto branco e amarelo) e indicadores de foco visíveis.
* **Leitura em Voz Alta (Web Speech API):** Narração completa do conteúdo da página ou de cartões individuais utilizando síntese de voz nativa do navegador (`speechSynthesis`).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico:** Uso de atributos ARIA (`aria-label`, `aria-pressed`, `aria-live`) e estruturação acessível.
* **CSS3:** Variáveis CSS, CSS Grid responsivo e tema de alto contraste.
* **JavaScript (ES6+):** Manipulação do DOM, filtragem de arrays e integração com a *Web Speech API*.
